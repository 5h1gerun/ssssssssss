## 絶対に守ること（ガイドラインの3原則）

1. 作品の核となる体験・見聞きしたこと・気づき・伝えたいことは **自分自身のもの** であること
2. AIをどのように使ったかを **申告する** こと（正直な申告で不利にはならない）
3. 作品に書かれた体験は **事実** であること。AIに架空の体験談を作らせない

申告内容と実際の制作方法に大きな相違があると、審査対象外や受賞取消しの可能性がある。
だからこそ、このリポジトリに制作過程（プロンプト、判断、修正）を残していく。
